Quick start

Up and running in a minute

Install — drag & drop the .zip into Blender, or use Preferences → Add-ons.

Open the Overlays dropdown in the 3D Viewport.

Enable the Check Mesh section and the checks you need.

Model freely — flaws are highlighted live in your colors.

Which Blender versions are supported?

Blender 4.2 and newer, on Windows, Linux and macOS (Apple Silicon and Intel).

Will it slow down my viewport?

Version 3.0 runs its analysis in a native, multithreaded core, built to keep up with dense meshes while you edit. You can also set a face-count limit above which overlays are skipped.

Do I get updates?

Yes — updates are delivered through your Gumroad library. Download the new package and install it over the old one.
